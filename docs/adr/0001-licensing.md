# ADR 0001：主项目及第三方许可证

状态：建议，待所有者确认。日期：2026-10-11。

2026-10-11 更新：所有者明确要求创建并推送 GitHub 仓库，授权首次提交及私有远程保存。此次提交不授予开源许可，不纳入第三方参考原稿/归档、上游研究源码或采集数据；许可证和权利人仍待确认。原首次提交门禁依本次明确授权放行，正式 LICENSE/NOTICE 与公开发布条件保持待定。

推荐主项目原创代码采用 Apache-2.0，以明确授权与专利条款支持企业集成；MIT 为简化许可的备选。产品商业模式、开源范围与权利人尚未明确，当前不创建具有正式授权效力的 LICENSE，也不宣称主项目已经开源。

依赖按版本登记许可证及 NOTICE。Firecrawl 主仓库以 AGPL-3.0 为主，部分目录另有许可，不能根据服务隔离直接断言无义务。源码复制、修改或部署前按实际组合评估。

参考资料属于第三方或用户提供的材料，不包含在主项目拟议授权内。公开发布前排除这些副本或取得许可。

完成条件：所有者确认许可及权利人；创建 LICENSE/NOTICE；README 与包元数据一致；依赖清单完成实际版本审查。该决策文件落地不表示 G01 的正式许可及首次提交已完成。


G01 放行信号：项目所有者明确确认主项目许可证、版权权利人名称及可纳入首次提交的文件范围（含参考素材是否仅内部保留）。记录确认日期后，1 个工作日内创建 LICENSE/NOTICE、同步 README、审阅并完成本地首次提交。首次提交不依赖远程仓库；G02 单独配置远程。尚未下载的依赖登记为待审查，不以未完成的全量版本审查阻塞仅含基础文档的首次提交；实际接入和发布前必须完成对应审查。没有收到确认不计入该时限，状态保持待确认。
