# ADR 0001：主项目及第三方许可证

状态：已采用。日期：2026-10-11。

所有者先授权首次提交及私有远程保存，随后明确要求将项目开源。按此前推荐选择 Apache-2.0，版权声明使用“OmniCrawler Agent contributors”，不推定具体个人或公司的权利归属。LICENSE 为 GitHub 官方许可证 API 提供的 Apache-2.0 全文；NOTICE 记录项目声明与第三方边界，README 和包元数据一致。

开源范围为已提交的原创代码、测试、配置和设计文档。第三方参考原稿/归档、上游研究源码、运行数据和本地工具状态继续排除；公开前检查完整 Git 历史和当前提交范围。GitHub 仓库改为公开，main 为默认分支。

直接运行依赖的版本与包许可元数据记录于 docs/third-party-dependencies.md。传递依赖、浏览器二进制和候选插件的目录级许可尚未全量审查；发布包含这些组件的镜像或二进制前须按实际组合审查并保留 LICENSE/NOTICE。当前仓库和项目构建产物不包含第三方源码或浏览器。

Firecrawl 主仓库以 AGPL-3.0 为主，部分目录另有许可，当前未接入或再分发；未来源码复制、修改或部署时按实际组合重新评估。主项目许可不重新授权第三方组件或参考材料。

原首次提交门禁已由所有者明确推送指令放行；本次明确开源指令放行许可证创建及仓库公开。原关于等待确认的记录属于历史状态，不再作为当前执行门禁。
