# ADR 0002：首版采集网络与插件边界

状态：首版实现。日期：2026-10-11。

直接让多种浏览器/爬虫自行请求网络会增加 DNS、重定向、子请求的一致性风险。首版集中使用校验 DNS 且固定已校验地址的 HTTP 传输获取公开页面，禁止环境代理，逐跳检查并遵循 robots 与访问拒绝。

Crawl4AI 负责受控取得 HTML 的内容解析，CSS 字段从原始 HTML 读取以保留实体属性。Playwright 只执行已获取 HTML 内联脚本，保持断网与沙箱，阻断 HTTP/WebSocket 并禁用 WebRTC/Service Worker；不支持网络依赖型 SPA。

自动路由按显式 ready_selector 或已安装可选引擎决定，不预测任意网站行为；拒绝后停止。未来网络浏览器需受控代理或容器出站策略后再开放，不能仅用 DNS 预检代替传输边界。

模块化单体使用平坦 Python 模块先交付闭环；核心算法不依赖网页引擎。SQLite 存放原子结构化快照与证据，避免首版文件/数据库双写失败。API/MCP 单 worker 文件锁；Windows 多服务进程尚不支持。

验证由本地授权 HTTP、真实浏览器渲染、API/MCP 协议、快照变化及删除回归测试构成。未对外部署，不承诺全网成功率或百万页容量。
